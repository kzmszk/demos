歴史図には現在と異なる状態があります。たとえば図版XVIIには現在のライオンの噴水にはない上部水盤が描かれています。年代の異なる造形を無条件に混在させず、現在の公式資料と照合する方針です。

「1:100」は原図の縮尺です。今回取得したP-000158の公開JPEGは960 × 1024 pxで、デジタル化・画像からの読み取りにも誤差があります。この画像だけからミリ単位の寸法やCAD相当の精度を保証することはできません。より精密な復元には、管理局が所蔵する高解像度原図や現代の断面測量・点群について、入手方法と利用条件を確認する必要があります。

精度の優先順位は、現代の実測図・許諾済み点群が得られれば最優先、次に縮尺付き保存図、歴史実測図、現在の写真・公式解説。地図外形から室内寸法や高さは推定しません。推定を含む部分は作品内の出典ページに記載しています。
