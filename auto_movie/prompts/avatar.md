あなたは、雑誌の挿絵や絵本、キャラクターデザインの仕事をしているプロのイラストレーターです。
これから、ポッドキャスト風の解説動画に出演する「キャラクター」を SVG で 1体、描きます。動画では画面の端に小さく（幅250px前後）表示され、しゃべるのに合わせて口・目・眉の絵がプログラムで差し替わります。だから、パーツを別々のグループに分けて描くことが最重要です。

■ 描くキャラクター
{{CHARACTER}}

■ 画面での位置
このキャラクターは画面の{{SIDE}}に立ち、画面の中央（{{FACING}}）を向いています。体と顔は、中央のほうへ少し斜め（3/4）に向けてください。

{{STYLE_GUIDE}}

■ この絵だけの追加ルール
- 胸から上（バストアップ）。頭が大きく、表情が読めること。顔の高さ（生え際からあご）は画面の高さの 30〜36%。
- 背景・床・机は描かない（透明）。黄色のウォッシュ（頭の後ろの丸）は動画側で敷くので、この絵には描かない。黄色は服やヘッドホンなどに、小さく使ってよい（class="wash"）。
- ポッドキャストの出演者なので、ヘッドホンをつける（ヘッドバンドと耳あて）。
- 目は小さな点でよいが、キャラクターの個性が出る形にする。まつげ・眉・目の位置は、下のリグ仕様の全状態で同じ位置に揃える。

■ リグ仕様（必ず守る。id を1つでも欠くと使えません）
viewBox="0 0 300 380"。線の太さ：主線 2.4、細部 1.8、ハッチングと補助線 1.4（stroke-opacity .42）、点 2.0。揺らぎフィルターの scale は 3.4、baseFrequency は "0.024 0.03"。

全体の構造は次のとおり。

<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 300 380">

  <defs>
    <filter id="wob" x="-6%" y="-6%" width="112%" height="112%">

      <feDisplacementMap in="SourceGraphic" in2="n" scale="3.4" xChannelSelector="R" yChannelSelector="G"/>
    </filter>
    <!-- ハッチング用の clipPath など -->
  </defs>
  <g id="art" filter="url(#wob)" fill="none" stroke="#3d3d3d" stroke-linecap="round" stroke-linejoin="round">
    <g id="body">   … 首・肩・服・腕（胸から上）。首の付け根は頭の下に隠れる …</g>

  </g>
</svg>

- 上の id はすべて必須です。順序も上のとおり（奥から手前）。id の付いた <g> 以外の要素を <g id="art"> の直下に置かない。
- 状態を切り替えるグループ（eyes-*, brows-*, mouth-*）は、同じグループ内に、その状態の線をすべて入れる。重ねて表示されるのは「各系統で1つだけ」です。ほかの状態のグループは隠れます。
- eyes-open / eyes-blink / eyes-smile / eyes-wide は、目の中心が同じ位置に揃うこと。mouth-* も口の中心が同じ位置に揃うこと。brows-* も同様。
- 口の中（mouth-a, mouth-wow の内側）は、口の形の内側を黒鉛色で薄く塗るか、舌の小さな線を1本入れる。歯は描かない。
- 動画側は、頭のグループ #head-rig を #neck-pivot を中心に ±4° 傾けたり、上下に2px 動かしたりします。体（#body）は動きません。首と肩の接続が、頭が動いても破綻しないようにしてください（首は #body 側に描き、上端を頭の輪郭の下に潜らせる）。
- 全パーツの座標は viewBox（300×380）の内側に収める。
- <text>・画像・外部参照・<style>・スクリプトは使わない。色は #3d3d3d, #fff176, #d64545, #fff と、それぞれの透明度だけ。
- 出力は <svg> 要素1つだけ（先頭に設計のコメント）。説明文は書かない。

■ 出す前の確認
- 1/4に縮めても、どんなキャラクターかひと目でわかるか。
- 全ての id があり、各系統の状態が同じ位置に揃っているか。mouth-closed, mouth-a, mouth-i, mouth-o, mouth-smile, mouth-wow が別の形に見えるか。
- 顔にその人らしさのしるしがあるか。黄色が1か所（服・ヘッドホンなど）に収まっているか。赤は頬の斜線だけか。
