# 参考資料：忘却曲線と、復習のタイミング

## 1. 忘却曲線（エビングハウス、1885年）
- ドイツの心理学者ヘルマン・エビングハウスは、意味のない文字の並び（例：「DAX」「BOK」のような無意味綴り）の一覧を自分で覚え、時間をおいて覚え直すときに、最初よりどれだけ手間が減るか（節約率）を測った。節約率は「まだ覚えている割合」の目安として使われる。
- 記録された節約率（覚えてからの時間 → 残っている割合）：20分後 約58%、1時間後 約44%、約9時間後 約36%、1日後 約34%、2日後 約28%、6日後 約25%、31日後 約21%。
- 読み取れること：忘れるのは最初の1日がとくに急で、約3分の2（66%）が失われる。その後の減り方はゆるやかで、1か月後でも2割ほどは残る。この形の曲線を「忘却曲線」と呼ぶ。
- 2015年に Murre と Dros が同じ手順で追試を行い、ほぼ同じ形の曲線が得られた（学術誌 PLOS ONE）。
- 注意：実験は「意味のない文字列」を使ったもの。意味を理解した内容や、関心のある内容は、これほど急には忘れない。個人差も大きい。

## 2. 分散学習（間隔をあけた復習）
- 同じ回数勉強するなら、一度にまとめてやるより、間隔をあけて分けたほうが長く記憶に残る（分散効果）。多数の研究（Cepeda ら、2006年のレビューなど）で一貫して確認されている。
- 最適な間隔は、「いつまで覚えていたいか」によって変わる。よく紹介される目安が「1日後・1週間後・1か月後」に復習する方法。厳密な定説ではなく、あくまで実用的な目安。
- 復習のたびに、次に忘れるまでの時間が伸びていく。忘れきる前に思い出すほうが、忘れてから覚え直すより少ない労力で済む。

## 3. 思い出す練習（テスト効果）
- Roediger と Karpicke（2006年）の実験：文章を勉強したあと、1週間後のテストの正答率は、読み直しを繰り返したグループが約40%、思い出す練習（自分で書き出すテスト）をはさんだグループが約61%だった。
- 勉強した5分後のテストでは、読み直したグループのほうが成績がよかった。1週間後に逆転した。読み直しは「分かった気になる」ため、その場では手応えがあるが、長くは残らない。
- ノートを閉じて、まず自分の力で思い出そうとすること自体が、記憶を強める。思い出せなくても、その努力に効果がある。答え合わせは思い出したあとで行う。

## 4. 実践のコツ
- 勉強した日に、スマホのカレンダーに復習の予定を3つ入れる（1日後・1週間後・1か月後）。
- 1回の復習は5分ほどで十分。ノートを閉じて、要点を思い出して書き出し、そのあと答え合わせをする。
- 「読み返す」のではなく「思い出す」ことがポイント。
