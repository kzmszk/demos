# SAGRADA FAMÍLIA — Web Walk & Fly

2026年10月1日のサグラダ・ファミリアを目指した、歩行・飛行で見学できる3D再構成です。確認できた公式工事資料の最新日は **2026年9月22日** です。10月1日の現地測量や、完成予想図ではありません。

公開URL: https://demos.polynous.io/sagrada-familia/ （従来の workers.dev URLも利用できます）

イエス・キリスト塔は外装完成・内部工事中として扱い、塔内部への進入を制限しています。栄光のファサードなどの未完成部分を残し、将来の完成形と混同しない構成です。クレーンや工事区画の細部には資料からの推定を含みます。

PCのWebGL 2対応ブラウザ向けです。初回読み込みは約325MBで、展開時には追加のメモリが必要です。WebAssembly、Web Crypto、Streams、gzip対応のDecompressionStreamを使用します。実機検証はChrome / RTX 4090で行いました。モバイル、Safari、Firefoxは未検証です。

## 配布と更新

- `public/` は検証済みV12のHTML、Godot実行データ、出典・ライセンス文書です。`assets/3bdfbd54d95a902bb0d2/` に版を固定しています。
- `demo.json` の `serve: "public"` により、この配布フォルダだけがギャラリーに入ります。
- `SOURCE.json` は取込元と全配布ファイルのSHA-256、ブラウザ検証済みであることを記録します。公開フォルダ外に保持します。
- `../gallery/covers/sagrada-familia/01.png` と `02.png` はV12の実際のWeb画面（生誕のファサード／身廊）を加工せずコピーしたものです。オフラインレンダーではありません。`shots: []` により通常の自動撮影では置き換えません。

編集ソースと再生成に必要な素材は、このリポジトリの `src/`・`runtime/`・`assets/`・`web/` に保存しています。制作時の元フォルダ `/home/kazu/work/codex/2026-10-01/task-6/sagrada_familia_2026/` には、完成済みBlender原本 `build/Sagrada_Familia_2026.blend`、GLB、検証済みの `web/site_bundle/` も残っています。通常のギャラリービルドではこれらを再生成しません。

## クローン後・既存Web版の復元

`npm run build` は `demo.json` の `prebuild` から `restore-web.mjs` を実行します。`public/` があれば全ファイルを `SOURCE.json` と照合し、なければ公開URLから約325 MBを取得して、全ファイルのサイズ・SHA-256が一致したものを配置します。Blender/Godotの起動はありません。

公開版の更新などで元の配布ファイルを取得できない場合は、次の手順で保存済みの検証済み `site_bundle/` を取り込みます。既存の `public/` に不一致や余分なファイルがある場合は、自動で上書きせずエラーにします。

## Web版を更新・取り込みする

元作品を更新したら、独立ソース側でWeb版の書出し・分割・ブラウザ検証を終え、次を実行します。既存作品の未公開変更があるときは、公開済みのGit状態を基準に専用worktreeで統合してください。

```bash
node sagrada-familia/import-web.mjs /absolute/path/to/web/site_bundle
npm run build
npm test
npm run deploy
```

取込時はサイズとSHA-256を検証し、単体20MiB以内で分割配布します。総ダウンロード量を減らす仕組みではありません。ギャラリーへ戻るリンクと、公開ホストではローカルQA送信UIを無効にする処理をHTMLに加えます。モデル・素材・実行データは元パッケージと同一です。初回公開時のV12と、現在のコミット済みソースから生成したクレジットの両方に対応します。

`package_static.py` が作る新規パッケージの `browser_tested` は `false` です。`verify_static.py` だけでは実ブラウザ検証の代わりになりません。ロード・描画・歩行／飛行・床復帰・Escなどをそのパッケージで検証した後、対応する検証記録を保存して `package_manifest.json` の `browser_tested` を `true` にします。取り込みではこのフラグを必須とし、検証を省略しません。

取り込みは `demo.json` の出典リンクも新しいパッケージIDへ更新します。取り込み後は、更新された `SOURCE.json` と `demo.json`、スクリプト、説明文、必要ならカバー画像をコミットします。`public/` は生成物としてGit対象外です。公開版V12のクレジットに含まれるGit操作への言及と、以下の2026年10月2日の記録は、当時の制作・取り込み時点の履歴です。

## 出典と再現の限界

作品内の **資料と出典** に、全出典台帳、撮影者、出典URL、写真素材のCC BY / CC BY-SA、改変内容、Godot・フォントのライセンスを保持しています。撮影者のCCライセンスと、写真に写る彫刻・ガラス作品そのものの権利は別に記録しています。作品全体への一括ライセンスや無制限な3D複製許諾を示すものではありません。

公式の測量モデル・写真測量モデルではありません。彫刻は写真を用いた立体レリーフで、側面と奥行きに推定があります。一部の窓図像は反復配置で、全窓の正確な図像・配置を再現していません。樹木状の柱、ヴォールト、石材や接合部、天井の局所的な閉塞面は写真との比較に基づく造形上の近似です。光は鑑賞用で、特定日時の太陽位置を検証したものではありません。周辺市街、塔内部の全階段・見学経路は対象外です。

独立ソースの `docs/DELIVERY_V12.json`、`docs/FINAL_SOURCE_AUDIT.json`、`docs/VISUAL_REVIEW_V12.json`、`docs/VALIDATION_WEB.md` に制作・検証記録があります。
