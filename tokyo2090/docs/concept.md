# TOKYO 2090 — 滑空する廃都（仮題）

> 作業メモ。題名は未定。候補: 「マント」「2090」「サキと空」「渋谷、滑空」

## 世界

- 2090 年。2030 年ごろ、原因不明の混乱で 1 年のうちに人類の 99 % が死んだ。
- 以来 60 年、東京は誰にも手入れされていない。ビルは剥落し、ガラスは落ち、
  高層ビルのいくつかは上層が崩れている。街路樹は森になり、ツタが外壁を覆い、
  アスファルトを割って木が生えている。地上には放置された自動車が列をなす。
- 電気はない。夜は月と星だけ。火を焚く煙がときどき遠くに見える。
- 生き残りは全員 18 歳。みな同じ能力を持つ。
  - **マント**: 腕と足で張ると翼になり、グライダーのように滑空できる。
    上昇気流やビルの壁沿いの風をつかめば上昇もできる。
  - **テレパシー**: 声を出さずに会話できる。距離があっても届く。

## 登場人物

- 気候変動で 2090 年の東京は暑い。生き残りの服は最低限。靴ではなく手作りの革サンダル。
- **自分**（男、18）: 一人称。日に焼けた腕と手、マントを留める革のハーネスをかけた素肌の胸、
  短いズボン、革サンダル。
- **サキ**（女、18）: いつも一緒に飛ぶ。先を飛んで道を示す。テレパシーで話しかけてくる。
  自分で切った短い黒髪。胸を覆う袖なしの短いトップと腰に巻いた短い布だけで、腹・肩・腕・脚は
  風に焼けた素肌。革のハーネスで褪せた朱色のマント（画面でいちばん強い色）を留める。
  ほのかな色気はあるが、ポーズをとらせない。健康的で自然に。

## 遊び

- フライトシミュレータ寄り。揚力・失速・バンクがそれらしく効く。
- 飛び始めは屋上から**飛び降りる**。落ちながら速度をつけて滑空に入る。
- 飛んでいるあいだは、ビル壁の上昇風、日向の屋上の熱上昇、谷筋の風で**上昇できる**。
- ビルを**ポイント**すると屋上に降りて一休みできる（着地点が光る）。
- サキはつねに視界のどこかにいて、テレパシーの短い言葉で誘う。
- 舞台は渋谷・新宿・六本木。2020 年代の実データ（PLATEAU 東京23区 LOD2 + OSM）
  を元に、高いビルをランダムに崩して 60 年分の廃墟化を施す。
- 終末感は漂うが、空を自由に飛べる爽快感が主役。

## 絵の方向（イメージボード共通）

- 画面そのものが絵。全画面、文字はほぼ出さない。
- 色: くすんだ緑と錆、暖かい斜光、薄い靄。朱色のマントだけが鮮やか。
- 構図: 極端なスケール対比（巨大な廃ビル / 小さな二人）、余白の多い空。
- 写実寄りのペインタリーなコンセプトアート。漫画的な線は使わない。

## データ

- 建物: PLATEAU 東京都 23 区 (CityGML, LOD2 屋根形状あり) + OSM。
- 地形: 国土地理院 DEM 5 m。
- パイプラインは kyoto / alhambra の tools/gen を流用する。
