# Kinetic Manifesto — 014 のテンプレート化

`prompts/014-kinetic-manifesto.txt`（改修版プロンプト v2）の実装です。
スクロールで再生するキネティック・タイポグラフィのページを、**エンジン1つ＋原稿JSON 1枚**から何枚でも生成します。
デザインと動きはエンジン側に固定し、文言・シーン構成・3色だけを JSON で差し替えるので、量産しても品質が落ちません。

- 日本語 / 英語の両方に対応しています（和欧混植も可）。
- 文言はブラウザ上の編集パネルで直せます。コードに触る必要はありません。
- 出力は外部リソースゼロの単体 HTML です。`file://` で開いてもオフラインで動きます。

## すぐ試す

```bash
python3 -m http.server 8417 --directory /home/kazu/work/demos
```

- 開発プレビュー: http://localhost:8417/kinetic/index.html?c=move-ja
  - `?c=` には `content/` にある JSON の名前を指定します（`move-ja` / `move-en` / `ma-ja`）。
- 生成済みページの一覧: http://localhost:8417/kinetic/dist/

## ブラウザで文言を直す

1. ページで **E キー** を押すか、ヘッダーの「編集」を押します。URL の末尾に `#edit` を付けても開きます。
2. 右側の編集パネルで文言を直します。入力した内容はすぐにプレビューへ反映されます。
   - シーンのカードにフォーカスすると、そのシーンの完成状態が表示されます。「▶ 再生」を押すと、そのシーンの動きだけを再生できます。
   - シーンの動きの変更、並べ替え、追加、削除ができます。配色はプリセットから選ぶか、3色を直接指定します。
   - 推奨字数を超えた箇所やコントラスト不足などは、該当する欄の下に警告が出ます。
3. 編集内容はこのブラウザに**下書きとして自動保存**されます。下書きを表示している間は、ヘッダーに「下書き」と出ます。
4. ファイルに反映するには **「HTMLを保存」** を押します。編集後の原稿を埋め込んだ単体 HTML がダウンロードされます。
   - 「JSONを保存」は原稿だけを書き出します。量産ラインの `content/` に戻す用途です。
   - 「読み込む」では JSON を読み込めます。以前このテンプレートで書き出した HTML も読み込めます。パネルへのドロップでも読み込めます。

書き出した HTML も、E キーで同じように再編集できます。編集ボタンを出したくない公開用ページは、ビルド時に `--lock` を付けます。

## 量産する

```bash
cd kinetic
cp content/move-ja.json content/my-page.json   # 原稿を書く
node build.mjs --check                         # 検証のみ
node build.mjs                                 # content/*.json → dist/<slug>.html + dist/index.html
node build.mjs content/my-page.json --lock     # 1枚だけ、編集ボタンなしで
```

- エラー（本文が空、記法の閉じ忘れ、不明な動き、不正な色）がある原稿はビルドされません。警告は表示されますが、ビルドは通ります。
- ブラウザの「HTMLを保存」と `build.mjs` は同じテンプレート（`src/js/template.js`）を使います。同じ原稿からはバイト単位で同一の HTML ができます。
- 原稿を LLM に書かせるときの指示書は `prompts/content-brief.md` にあります。

## 原稿（JSON）の書き方

```json
{
  "format": "kinetic-manifesto@1",
  "lang": "ja",
  "meta": { "title": "…", "description": "…", "slug": "ファイル名" },
  "palette": { "bg": "#0a0a0a", "fg": "#f1f1ec", "accent": "#c6ff00" },
  "intro": { "word": "MOVE", "kicker": "…", "sub": "…", "ticker": "…",
             "slate": { "prod": "…", "roll": "A", "take": "01", "date": "2026.09.25", "dir": "—" } },
  "scenes": [
    { "type": "assemble", "text": "すべては、\n欠片で届く。", "gloss": "Nothing arrives whole." },
    { "type": "split", "text": "つなぎ目こそ、", "insert": "本編だ。" }
  ],
  "finale": { "text": "君の番だ。", "gloss": "Your move.", "portal": "auto", "replay": "最初から再生" },
  "options": { "uppercase": true, "editable": true }
}
```

| 動き (`type`) | 見え方 | 本文の書き方 | 推奨字数（和 / 欧） |
|---|---|---|---|
| `assemble` | 散らばった文字が集まる | 改行で行を固定。改行がなければ文節で自動改行 | 18 / 32 |
| `stretch` | 各段が横に伸びて揃う | 1行＝1段、2〜4段 | 各段 5 / 10 |
| `split` | 刃で切られ、帯の文字が現れる | 切られる1行＋`insert` | 10 / 16、帯 16 / 28 |
| `cascade` | ドミノのように立ち上がる | 自由 | 20 / 36 |
| `prism` | 角柱が一面ずつ回る | 1行＝1面、2〜4面 | 各面 6 / 12 |
| `type` | タイプされる | `~~語~~` で打ち間違い、`{漢字\|かな}` で変換 | 30 / 48 |

- 最後のシーンは常にフィナーレです。タイトル語の「カウンター」（O・D・0・回・口・間 などの閉じた空間）へズームし、締めのページにつながります。カウンターは描画した字形から自動で検出するので、どんな語でも使えます。カウンターのない語の場合は、字の一番太い線の中へ入ります。
- `gloss` は小さな注記行です。和文ページなら英訳、英文ページなら和訳を入れると効果的です。
- シーン数は 3〜9（フィナーレ込み）を推奨します。同じ動きを連続させると警告が出ます。
- 配色は「文字/地 7:1 以上」「アクセント/地 4.5:1 以上」を推奨します（3:1 未満はエラー）。編集パネルのプリセット 8 種はすべてこの基準を満たしています。

## 日本語組版の仕組み

- **文節改行**: `Intl.Segmenter('ja')` の単語区切りをもとに、助詞・助動詞・送りがな・句読点・小書き仮名を前の語に結合して文節単位にまとめます。そのうえで、文字が最大になる行数と改行位置を選びます。禁則処理も行います。
- **字間**: 表示行には `palt` を効かせています。1文字ずつ動かすために文字を分解しても、元の文字列を実際に組んで測った送り幅（Range の矩形）を使うので、詰めやカーニングは崩れません。
- **タイプ演出**: かなを下線付きで入力し、アクセント色で変換を確定する流れを再現します。折り返しは文節の単位でしか起きません。
- **書体**: 日本語を含む文字列にはゴシックの W8 級を、含まない文字列には欧文のコンデンスト・グロテスクを使います。どちらもシステムフォントです（Mac: ヒラギノ角ゴ／Helvetica Neue Condensed、Windows: 游ゴシック／Arial Narrow・Impact、Linux: Noto Sans CJK JP Black／Nimbus Sans Narrow）。書体が変わっても、実測でレイアウトを合わせます。

## 操作

- スクロール: 再生（逆方向にも再生できます）
- 右端のレール（スマホでは下端）: 各シーンへ移動
- `1`〜`9`: シーンへ移動
- `0`: 先頭へ
- `M`: モーションのオン／オフ（`prefers-reduced-motion` の環境では最初からオフ）
- `E`: 編集パネル

## ファイル構成

```
kinetic/
  index.html          開発プレビュー。data-k-src の付いた資産が、この順でビルドに内包される
  build.mjs           content/*.json → dist/*.html（依存なし、Node 18+）
  content/            原稿（move-ja / move-en / ma-ja）
  dist/               生成物（単体 HTML と一覧 index.html）
  prompts/            プロンプト v2（現行）と改修前の v1、原稿執筆ブリーフ
  src/kinetic.css     スタイル（3色は JSON から CSS 変数で注入）
  src/js/
    util.js           名前空間 K、イージング、乱数、色、ストレージ
    text.js           書体スタック、文節分割、タイプ記法、実測、行分割
    content.js        シーン定義、ラベル、プリセット、正規化、検証
    portal.js         カウンター検出（塗りつぶし＋距離変換）
    scenes-a.js       assemble / stretch / split
    scenes-b.js       cascade / prism / type
    frame.js          タイトルカード / フィナーレ / 締めページ
    app.js            ランタイム（スクロール→進行度、ヘッダー、レール、キー操作）
    template.js       単体 HTML のテンプレート（ブラウザ書き出しとビルドで共用）
    export.js         ブラウザからの書き出し
    editor.js         編集パネル
    dev.js            開発プレビュー専用（?c= の JSON を読む。ビルドには含まれない）
```

新しい動きを足すときは、`K.scenes.<名前> = { create(ctx) { return { layout, update } } }` を実装します。あわせて `content.js` の `K.TYPES` に尺と推奨字数を追加します。
