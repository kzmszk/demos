# 原稿執筆ブリーフ（Kinetic Manifesto 用）

Kinetic Manifesto テンプレートに流し込む原稿 JSON を LLM に書かせるための指示書です。
`{{ }}` の部分を埋めてから、下の区切り線以降をそのまま渡してください。

---

あなたはタイポグラフィとコピーライティングの両方に通じたアートディレクターです。
スクロールで再生するキネティック・タイポグラフィのページに流し込む「宣言文」の原稿を、次の JSON 形式で1つだけ書いてください。
JSON 以外の文章は出力しないでください。

## 依頼内容

- テーマ: {{例：「締め切り」についての宣言}}
- 言語: {{ja または en}}
- 語り口: {{例：短く、断定的で、少しユーモアがある}}
- 配色の希望: {{例：暗い地に明るいオレンジ ／ おまかせ}}
- 日付: {{例：2026.10.01}}

## 形式

```json
{
  "format": "kinetic-manifesto@1",
  "lang": "ja",
  "meta": { "title": "タイトル語 — 副題", "description": "120字以内の紹介文", "slug": "半角英数とハイフン" },
  "palette": { "bg": "#rrggbb", "fg": "#rrggbb", "accent": "#rrggbb" },
  "intro": {
    "word": "タイトル語",
    "kicker": "語の上に置く小さな行（和文なら英語の副題を添える）",
    "sub": "ひとことの紹介（40字前後）",
    "ticker": "下の帯に流れる短い語の連なり（— で区切る）",
    "slate": { "prod": "作品名", "roll": "A", "take": "01", "date": "YYYY.MM.DD", "dir": "—" }
  },
  "scenes": [
    { "type": "assemble", "text": "…", "gloss": "英訳（和文ページの場合）" },
    { "type": "stretch",  "text": "…\n…\n…", "gloss": "…" },
    { "type": "split",    "text": "…", "insert": "…", "gloss": "…" },
    { "type": "cascade",  "text": "…", "gloss": "…" },
    { "type": "prism",    "text": "…\n…\n…\n…", "gloss": "…" },
    { "type": "type",     "text": "…~~…~~…", "gloss": "…" }
  ],
  "finale": { "text": "締めの言葉", "gloss": "…", "portal": "auto", "replay": "最初から再生" },
  "options": { "uppercase": true, "editable": true }
}
```

## 書き方のルール

1. **宣言は6つ、それぞれ1つの考えだけを述べる。** 全体で1本の論旨になるように並べ、締めの言葉は読み手に行動を渡す一言にする。
2. **動きに合わせて書く。** 文言が動きの意味を運ぶようにする。
   - `assemble`（散らばった文字が集まる）: 断片・集合・到着を感じさせる文。18字以内。
   - `stretch`（各段が横に伸びる）: 時間・長さ・余白・引き延ばしの文。改行で2〜4段に分け、各段は5字以内。
   - `split`（1行が切られ、帯の文字が現れる）: 前半が切られ、後半が中から現れる構造にする。`text` は10字以内、`insert` は16字以内。
   - `cascade`（ドミノのように立ち上がる）: 連鎖・順番・波及の文。20字以内。
   - `prism`（角柱が一面ずつ回る）: 見方を変える・言い換える文。改行で2〜4面に分け、各面は6字以内。
   - `type`（タイプされる）: 書き直し・訂正の文。`~~消される語~~` を1か所だけ入れ、漢字語は `{漢字|かな}` と書いてかな入力からの変換を見せる。見える文字は30字以内。
3. **英語の場合**の目安は、assemble 32字、stretch は各段10字、split 16字＋insert 28字、cascade 36字、prism は各面12字、type 48字、締め16字です（空白は数えない）。
4. **タイトル語**は和文なら1〜4字、欧文なら2〜8字にする。**閉じた空間（カウンター）を持つ字**を必ず含める。例：O・D・B・0・8、回・口・日・目・間・国。最後にこの空間の中へカメラが飛び込む。
5. **配色**は3色のみ。文字と地のコントラストは7:1以上、アクセントと地は4.5:1以上。アクセントは彩度の高い1色にする。
6. **決まり文句を避ける。**「未来を創る」「可能性は無限大」のような言い回しは使わない。具体的な名詞と動詞で書く。
7. 事実を述べる場合は正確に書く。架空の人物・団体を出す場合は架空とわかるようにする。
8. `gloss` は直訳ではなく、同じ強さを持つ短い訳にする。

## 提出前の確認

- [ ] 6つの宣言がすべて異なる動きで、同じ動きが連続していない
- [ ] 字数の上限を超えていない（改行した段・面ごとに数える）
- [ ] `~~…~~` と `{…|…}` の記号が閉じている
- [ ] タイトル語にカウンターのある字が含まれている
- [ ] 色がすべて `#rrggbb` 形式で、コントラストの条件を満たしている
- [ ] JSON として正しい（末尾カンマなし、改行は `\n`）

できた JSON は `kinetic/content/<slug>.json` に保存し、`node build.mjs --check` で検証してから `node build.mjs` でページにします。
