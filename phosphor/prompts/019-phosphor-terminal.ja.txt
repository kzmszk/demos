=== プロンプト（実際に使用したプロンプトの訳） ===
レトロな CRT 端末の OS シミュレーション「HELIOS/OS v2.3」を作ってください。全画面を蛍光グリーン（文字 #33ff66・背景 #031a07）とし、アンバー（文字 #ffb000・背景 #1a0f00）とアイス（#9fe7ff）のテーマも用意します。CRT の効果は CSS／canvas で表現します：走査線、控えめな画面の湾曲（ビネット、角丸、内側シャドウ）、text-shadow による蛍光体のグロー／ブルーム、穏やかなちらつき、流れるリフレッシュバー。読み込み時には、本物らしい BIOS の起動シーケンス（カウントアップするメモリチェック、デバイス一覧）に続いてログインバナーを表示します。入力行と点滅するブロックカーソルを備えた、実際に動くシェルを用意し、次に対応させます：help、ls、cat <file>（詩やミッションログを含む、短い架空のファイルをいくつか）、clear、date、whoami、theme <green|amber|ice>、matrix（数秒間の文字の雨）、weather（アスキーアート）、snake（端末の中で遊べる小さな ASCII のスネークゲーム）、↑／↓ によるコマンド履歴、タブ補完。書体は等幅フォントのスタックです。キーボード操作を基本とし、スマートフォンではタップでフォーカスしてソフトウェアキーボードが出るようにします。打鍵音はオプションです（Web Audio のクリック音、初期状態はオフ）。

共通要件（この100ページのコレクションの全ページに適用）：
1. 単一のスタンドアロン HTML5 ファイルとする。CSS はすべて <style> に、JavaScript はすべて <script> にインラインで書く。外部リソースは一切使わない：CDN、ライブラリ、Web フォント、外部の画像／SVG／音声ファイル、ネットワークリクエストはすべて不可。ビジュアルはすべて CSS、インライン SVG、Canvas、手続き的なコードで作る。
2. 妥当な HTML5 であること：<!DOCTYPE html>、<html lang="en">、<meta charset="utf-8">、viewport の meta タグ、意味のある <title> と meta description、正しく入れ子になったセマンティックなマークアップ、重複しない id、コントロールへの label／aria 属性、アクションには <button type="button"> を使う。
3. 書体はローカルのシステムフォントスタックだけを使い、必ず総称ファミリーで終える。ディスプレイ用の文字は SVG や Canvas で描いてもよい。
4. 360px のスマートフォンから大型デスクトップまでレスポンシブにし、ページに横スクロールを出さない。canvas はコンテナと devicePixelRatio（上限2）に合わせ、リサイズ時にレイアウトし直す。
5. ファイルを直接開いて（file://）オフラインで動くこと。コンソールエラーを出さない。ストレージへのアクセスは try/catch で保護する。
6. モーションは requestAnimationFrame と transform／opacity で滑らかにする。必要な箇所では、タブが非表示のあいだアニメーションを止める。prefers-reduced-motion を尊重し、落ち着いた代替表示を用意する。
7. Pointer Events でマウスとタッチの両方に対応する。:focus-visible のスタイルをはっきり見せ、意味のある場面ではキーボード操作に対応する。
8. 音はすべて Web Audio API で合成し、ユーザー操作の後にだけ鳴らし始め、目に見えるミュート／切り替えを用意する。
9. 上質な仕上げ：意図のある配色と余白、磨き込んだマイクロインタラクション、操作する前から美しい最初のフレーム、オリジナルのコピー（lorem ipsum は不可）。事実に関する内容は正確であること。架空のブランド・人物・データは、架空だとはっきりわかるようにする。
10. 品質基準：視覚的に印象的で、ブックマークしたくなる、ショーケース級の上質さを持ち、嬉しい細部に満ちていること。コンセプト、レイアウト、配色、書体、モーションのすべてで、ほかの99ページとはっきり異なること。


=== 概要 ===
HELIOS/OS v2.3「Aphelion」は、中継ステーションに搭載された架空のモノクロ端末 Heliograph HX-14 で動く、1987年の架空の OS です。ページ全体がモニターそのもので、電源 LED、刻印入りのバッジ、物理キーの列を備えたグラファイト色のベゼルが、湾曲して光るブラウン管を囲みます。ブラウン管はビームが開いて画面になるアニメーションで点灯し、POST 画面（メーカーの太陽マーク、カウントアップするメモリテスト、デバイス検出、カーネルのプログレスバー、サービスチェック）を流します。続いてオペレーターのログインを自動入力し、neofetch 風のウェルカム画面を表示します。罫線文字で組んだ HELIOS のロゴ、ブロック文字の濃淡で描いた太陽の紋章とその横のシステム情報カード、短い今日のメッセージ（MOTD）です。その先は実際に動くシェルで、小さな架空のファイルシステムと、ささやかなストーリー（ミッションログ、解読された信号、誰かが tty3 に残した詩）があります。蛍光体は3種類から選べます：P1 グリーン（文字 #33ff66・背景 #031a07）、P3 アンバー（文字 #ffb000・背景 #1a0f00）、アイス（#9fe7ff）。

=== 主な視覚技法 ===
- ブラウン管はレイヤーを重ねて作る：放射状の蛍光グラデーション、3px の走査線、かすかな RGB のアパーチャーグリル縞、低解像度の canvas に描いて動かすフィルムグレイン、流れるリフレッシュ帯、不規則で段階的なちらつき、湾曲したガラスを表す深い内側シャドウ付きのビネット、ガラスの映り込みハイライト。
- すべての文字に3層の text-shadow でブルームをかけ、見出しにはさらに明るい「ホット」なグローをかける。反転表示のタグとステータスラインもある。色はすべてテーマごとの CSS カスタムプロパティで制御する（rgba のグロー用に RGB の三つ組も持つ）。
- 電源オン／オフのアニメーション（水平のビームがラスターに広がり、消えるときは点に縮む）は、管面にかける CSS キーフレームと、別に用意した光るビーム要素で作る。
- テーマを切り替えると「消磁（デガウス）」の揺れが走る（skew、scale、hue-rotate のキーフレーム）。ときおりランダムな同期ずれのグリッチでラスターが跳ねる。
- 蛍光体の残光：画面をクリアすると、それまでの文字をゴーストレイヤーに複製し、ぼかしながらフェードアウトさせる。
- 出力は擬似的な回線速度（既定は19200ボー、`baud` で変更可）で流れ、アニメーションフレームごとにテキストノードへ文字を足していく。
- 文字の雨は canvas に描く：左右反転したカタカナ、ギリシャ文字、数字のグリフ、光る先頭の文字、フレームレートに依存しない半透明の軌跡、ランダムなきらめき。終わりはフェードアウトして元の文字を戻す。
- スネークゲームは端末の中に HTML として描く：罫線文字の枠、点を敷き詰めたフィールド、点滅する <> のエサ、尻尾に向かって網掛け文字 █ ▓ ▒ ░ の順に薄くなる胴体。
- ASCII の天気：手描きの天気アイコン5種、日付をシードにした予報、3日間の予報帯。
- バナーは、計測用の要素（プローブ）で測った端末の桁数に合わせて描き直す。そのため、スマートフォンから横長の画面まで、ロゴとシステム情報カードが崩れない。

=== 操作モデル ===
- キーボード中心のシェル：点滅するブロックカーソルの位置にコマンドを打つ。入力中はカーソルが点灯したままになり、入力欄からフォーカスが外れると中抜きになる。どれかのキーを押すかクリックすると起動を早送りする。
- コマンド：help、ls [-a] [-l] [dir]、cd、pwd、cat <file>、clear、date、whoami、theme <green|amber|ice>、matrix、weather、snake、history、echo、uname [-a]、uptime、fortune、sound <on|off>、baud <rate|max>、reboot。隠しコマンド（sudo、exit/logout、answer）と隠しファイル .plan もある。
- ↑／↓ でコマンド履歴をたどる。履歴は localStorage に保存される。Tab でコマンド、ファイルパス（ディレクトリを考慮し、隠しファイルは明示したときだけ）、コマンドの引数を補完し、候補が複数あるときは一覧を表示する。Ctrl+C で入力行を取り消し、Ctrl+L で画面をクリアし、Ctrl+U で行頭まで削除する。長い出力が流れている途中は、Enter／Esc／Ctrl+C で残りを一気に表示する。
- ベゼルのキーはよく使うコマンドを自動入力する（Help、Ls、Poem、Log、Weather、Snake、Matrix、Clear）。P1／P3／Ice キーと、画面内のステータス項目 [P1:GRN] で蛍光体を切り替える。Sound キーまたは [SND:OFF] で、Web Audio の音（打鍵のクリック音、Enter の重い打鍵音、エラーのビープ音、消磁の「ボン」という音）をオン／オフする。音は初期状態でオフで、AudioContext はユーザー操作があって初めて作る。
- スネーク：矢印キー／WASD で操作し、P か Space で一時停止、Q か Esc で終了する。タッチ端末では画面をスワイプするか、プレイ中にコマンドキーの代わりに現れる画面上の十字キーを使う。最高スコアは保存される。
- matrix：どれかのキーを押すかクリックすると、途中で雨を止める。
- スマートフォン：管面のどこかをタップすると、見えない実際の入力欄にフォーカスが移り、ソフトウェアキーボードが出る。レイアウトは visualViewport の高さに追従し、キーの列は横にスクロールする。
- 動きを減らす設定（prefers-reduced-motion）では、ちらつき、流れる帯、グレインのアニメーション、ビームと消磁の演出、出力の遅延を止めるので、起動は一瞬で終わる。
