=== 概要 ===
「ジュノのスケッチブック」は、架空のイラストレーター、ジュノのポートフォリオです。机の上に置いたリング綴じのスケッチブックとして作り、そばに鉛筆と消しゴムが転がっています。表紙はクラフト紙で、ゴムバンド、罫線入りのラベル、朱の落款、星、「hello!」の丸シール、型抜きの猫シールが付いています。表紙を開くと、ドット方眼のページ（#fbf8f1 に淡い青のドット）がパンチ穴に通した金属のワイヤーリングで綴じられています。中身は次のとおりです。自画像を添えた挨拶のメモ。選んだ仕事の2ページ（6つのプロジェクトを、マスキングテープで留めたポラロイドで見せる）。制作過程の走り書きのページ（サムネイル、冗談の「アイデアの数とコーヒーの杯数」グラフ、道具のチェックリスト）。航空便の封筒に書いた連絡先のページ（封筒が開いて手紙が出てくる）。すべてを黒鉛色 #3d3d3d で描き、蛍光ペンの黄色 #fff176 の塗りと、赤鉛筆 #d64545 のアクセント一色だけを添えます。どのイラストも、ページが現れると一本ずつ線を描いていきます。デスクトップでは本物の紙のようにページがめくれ、スマートフォンでは本を開いたまま一本の長いスクロールで読みます。

=== 主な視覚技法 ===
- 本物の2Dのページカール：つまんだ角と指先の垂直二等分線を折り目とする。ページの片側をクリップし、CSS の反転行列で紙の裏側のフラップを折り目に対して鏡映し、めくれた部分だけにクリップする。フラップの上の光沢の帯、ドロップシャドウ、下から現れたページに落ちる影の帯は、折り目に合わせて動かす。
- 紙が伸びないように角の位置を制約する（綴じ目の上端と下端のどちらからも、届く距離の内側に収める）。フラップは綴じ目を越えて向こうへ回り込み、ページがめくれきるにつれて消えていく。
- 手描きの揺らぎ：線画はすべて、少し不揃いに手で打ったパスに SVG の feTurbulence と feDisplacementMap のフィルターを通す。ホバーすると3種類のシードを切り替え、アニメーションの「線のふるえ（ライン・ボイル）」と小さな揺れを見せる。
- 自分で描かれるイラスト：すべての線を pathLength=1 にし、破線と間隔のパターンを間隔の側へずらしておく（丸い線端すら見えないように）。そこから遅延をずらしながら 0 へトランジションする。蛍光ペンは横に引かれ、赤い下線もあとから描かれる。
- リング綴じ：金属のグラデーションを付けたワイヤーを、インライン SVG のパターンで描き、CSS の radial-gradient で開けたパンチ穴に位置を合わせる。
- CSS で作る紙の小物：ギザギザにちぎった端（clip-path）のマスキングテープ（縞、ドット、方眼、黄色の柄）、ポラロイド、糊の帯のある付箋、小口のインデックスタブ、航空便の縞、ミシン目のある切手（radial-gradient のマスク）と消印、タービュランスで歪めたコーヒーの輪じみ。
- 紙の重なりが正しい封筒：フラップは 3D で回転して開き、半分まで開いたところで遅延付きの z-index のトランジションで手紙の後ろへ回る。手紙は不透明なポケットから上へ滑り出る。
- 鉛筆のカーソル（インライン SVG の data URI）。画面全体の canvas に薄い黒鉛の軌跡を残し、線の一片ずつが約1秒で消えていく。

=== 操作モデル ===
- デスクトップ：手描きの矢印ボタン、←／→ または PageUp／PageDown、Home／End、ページの角のボタン（Enter／Space）、色つきのインデックスタブ（途中のページをぱらぱらと素早くめくる）でページをめくる。ページの角をつまんで手でめくることもでき、離すとめくりきるか、元に戻る。
- スマートフォン（幅 860px 以下）：めくらない。ページを縦に積んでスクロールで読み、各ページにリングを付ける。各ページの絵は、スクロールで画面に入ったときに描かれる（IntersectionObserver）。
- 落書きやポラロイドにホバーすると揺れて線がふるえる。封筒はホバー、フォーカス、クリックで開き、手紙が読める。
- 「コピー」は（架空の、住所の形をしていない）連絡先の一行を Clipboard API でコピーする。使えないときはテキストを選択して案内を出す。
- 黒鉛の軌跡はマウスのポインターだけに付ける。prefers-reduced-motion では、絵をはじめから描き終えた状態で見せ、ページは即座に切り替え、揺れ、線のふるえ、軌跡を止める。
